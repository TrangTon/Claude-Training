# LS-101 Guests must be 1–6

## Problem
The form accepts 0 guests and shows a price (see Issue #1).

## Rule
R1: Guests must be a whole number from 1 to 6.

## Acceptance criteria
- Given valid dates, When guests = 0, Then show "Guests must be between 1 and 6." and no price.
- Given valid dates, When guests = 1 or 6, Then the price is shown.
- Given valid dates, When guests = 7, Then the same error is shown.

## Out of scope
Decimal guests (separate ticket), existing bookings.
